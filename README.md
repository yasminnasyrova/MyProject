# 🍓 Маджонг — Фруктовый Солитёр

Настольная игра-пасьянс в стиле маджонга, написанная на Python + Pygame. Убирай парные плитки с фруктами, пока доска не опустеет!

---

## 📋 Требования

- Python 3.8+
- [Pygame](https://www.pygame.org/) 2.x

Установка зависимостей:

```bash
pip install pygame
```

---

## 🚀 Запуск

```bash
python main.py
```

---

## 🎮 Правила игры

1. На доске расположены плитки с фруктами (70 штук, 35 пар).
2. Кликни на плитку — она выделится.
3. Кликни на вторую плитку с **таким же фруктом** — пара уберётся с доски.
4. Убирать можно только **свободные** плитки: у которых нет соседа слева **или** нет соседа справа.
5. Цель — убрать все плитки.

---

## 🕹️ Управление

| Действие | Описание |
|---|---|
| **ЛКМ по плитке** | Выбрать / снять выбор |
| **Новая игра** | Начать партию заново |
| **Перемешать** | Случайно перераспределить оставшиеся фрукты по плиткам |
| **Подсказка** | Подсветить одну готовую пару на 3 секунды |

## 🗂️ Структура проекта

```
├── main.py          # Точка входа, игровой цикл, отрисовка интерфейса
├── board.py         # Логика доски: расстановка, ходы, подсказки, перемешивание
├── tile.py          # Класс плитки: состояние, отрисовка
├── button.py        # Класс кнопки панели управления
├── fruit_draw.py    # Пиксельные спрайты всех фруктов
├── constants.py     # Все константы: размеры, цвета, список фруктов
└── README.md
```

## ⚙️ Настройки

Все ключевые параметры находятся в `constants.py`:

| Константа | По умолчанию | Описание |
|---|---|---|
| `COLS` / `ROWS` | 10 × 7 | Размер сетки плиток |
| `TILE_WIDTH` / `TILE_HEIGHT` | 74 × 90 | Размер одной плитки (пикселей) |
| `WINDOW_WIDTH` / `WINDOW_HEIGHT` | 1100 × 760 | Размер окна |
| `FPS` | 60 | Частота кадров |
